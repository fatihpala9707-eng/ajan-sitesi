<code>cipNo</code> özelliğini <b>private (−)</b> yap. Çip numarasını kimse değiştirmemeli!

<code>enerji</code> ya da <code>aclik</code> özelliğini <b>protected (#)</b> yap.

İpucu: Satırın başındaki + simgesine tıklayarak erişimi değiştir: + public → − private → # protected

${target.name}.__${key}()   ✖ private metot! Sadece ${esc(cname(target.kind))} sınıfının içinden çağrılabilir.

${jeep.name}.__sur()   ✖ private metot! Bakıcı dışarıdan çağıramaz.
